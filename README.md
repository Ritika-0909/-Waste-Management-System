# 🗺️ Dehradun Waste Collection Route Optimizer

An intelligent waste collection route optimization system developed using **Python, Streamlit, NetworkX, and Pandas**. The application helps optimize waste collection routes across Dehradun by calculating the shortest path, suggesting alternative routes, visualizing the road network, and providing waste bin analytics.

---

## 📌 Features

- 🚛 Calculates the shortest waste collection route
- 🛣️ Generates alternative routes
- 🗺️ Interactive Dehradun road network visualization
- 📍 Displays depot and waste bin locations
- 📊 Distance Matrix for all locations
- 🗑️ Waste Bin Fill Level Monitoring
- 📈 Road Network Analytics
- ⚡ Fast graph-based routing using NetworkX
- 📱 Interactive dashboard built with Streamlit

## 📍 Project Workflow

1. Select the Start Point (Depot)
2. Select the Destination
3. Choose the number of alternative routes
4. View the shortest route
